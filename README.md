# QuizMaster

## Про проєкт

QuizMaster — вебзастосунок для створення та проходження інтерактивних вікторин для дорослих і дітей.

Користувачі зможуть створювати власні вікторини, проходити тести інших користувачів, зберігати вікторини в обраному, залишати відгуки та переглядати статистику своїх результатів.

Мета проєкту — створити зручну платформу для перевірки знань, навчання та обміну інтерактивними тестами.

## Команда та розподіл ролей

Розподіл технічних та організаційних ролей буде визначено командою.

## Структура проєкту

- `frontend/` — клієнтська частина застосунку.
- `backend/` — серверна частина застосунку.
- `README.md` — опис проєкту.
- `.gitignore` — файли та папки, які Git не повинен відстежувати.

## Технології

Технологічний стек визначено командою та описано у файлі `TECH.md`.
