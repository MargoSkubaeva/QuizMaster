# QuizMaster

## Про проєкт

QuizMaster — вебзастосунок для створення та проходження інтерактивних вікторин для дорослих і дітей.

Користувачі зможуть створювати власні вікторини, проходити тести інших користувачів, зберігати вікторини в обраному, залишати відгуки та переглядати статистику своїх результатів.

Мета проєкту — створити зручну платформу для перевірки знань, навчання та обміну інтерактивними тестами.

## Структура проєкту

- `frontend/` — клієнтська частина застосунку.
- `backend/` — серверна частина застосунку.
- `README.md` — опис проєкту.
- `.gitignore` — файли та папки, які Git не повинен відстежувати.
- `TECH.md` — опис технологічного стеку проєкту.

## Технології

Технологічний стек буде визначено командою та описано у файлі `TECH.md`.

### Project Manager / Team Coordinator & Frontend Developer - Маргаріта
- Організація командної роботи та комунікації.

- Підготовка документації та щотижневих звітів.
- Контроль прогресу виконання завдань.
- Участь у розробці frontend-частини проєкту.

### Backend Developer — Андрій
- Розробка серверної частини застосунку.
- Створення API.
- Робота з базою даних.
- Реалізація авторизації та серверної логіки.

### Frontend Developer — Тамара
- Розробка користувацького інтерфейсу.
- Створення сторінок і компонентів.
- Реалізація навігації та стилізації.

### Тестування
- Маргаріта та Тамара — тестування frontend-частини, перевірка роботи інтерфейсу, навігації та відображення сторінок.
- Андрій — тестування backend-частини, API, авторизації та роботи з базою даних.

### Контроль якості
- Перед злиттям змін у `main` Pull Request має бути перевірений та схвалений іншим учасником команди.
- Знайдені помилки та зауваження фіксуються в GitHub Issues.
- Маргаріта координує процес перевірки та контролює виконання завдань.

### DevOps
- Андрій — налаштування середовища та підготовка розгортання backend.
- Маргаріта — налаштування збірки та підготовка розгортання frontend.
- Команда спільно узгоджує конфігурацію середовищ і процес розгортання застосунку.

## Запуск frontend
Frontend-частина QuizMaster розробляється з використанням HTML5, CSS3, Vanilla JavaScript та Vite.

### Встановлення залежностей
Перейдіть до папки frontend:

```bash
cd frontend
```
Встановіть залежності:

```bash
npm install
```
### Локальний запуск
Запустіть сервер розробки:

```bash
npm run dev
```

Відкрийте в браузері адресу, яку покаже термінал.
Frontend можна запускати незалежно від backend.

### Збірка проєкту
Для створення збірки виконайте:

```bash
npm run build
```
Після успішної збірки готові файли будуть розміщені в папці `frontend/dist/`.
